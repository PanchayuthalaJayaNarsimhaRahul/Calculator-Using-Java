Java Calculator
📌 Project Description

This is a simple console-based calculator application developed using Java. It allows users to perform basic arithmetic operations, including addition and subtraction, through an interactive menu.

The project demonstrates fundamental Java programming concepts such as methods, arrays, conditional statements, loops, and user input using the Scanner class.

✨ Features
➕ Addition: Adds two integers.
➖ Subtraction: Subtracts the second integer from the first.
🖥️ Interactive Menu: Displays available operations.
⌨️ User Input: Accepts two numbers from the user.
🔄 Continuous Execution: Allows users to perform multiple operations.
🚪 Exit Option: Provides an option to exit the calculator.
🛠️ Technologies Used
Programming Language: Java
Input Handling: Java Scanner class
Development Environment: Any Java-compatible IDE or text editor

🚀 How to Run
Step 1: Clone the Repository
git clone <your-repository-url>

Step 2: Navigate to the Project Directory
cd Java-Calculator

Step 3: Compile the Java Program
javac cal4.java

Step 4: Run the Application
java cal4
